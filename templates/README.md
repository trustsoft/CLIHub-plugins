# Plugin template

Copy `plugin.json` into `plugins/<id>/plugin.json` and replace every placeholder:

- `id` must equal the folder name.
- `version` must be `major.minor.patch` and must increase for every published change.
- `publisher`, `homepage`, and `minAppVersion` are required by the feed builder.
- `releaseNotesUrl` is optional.
- Keep only `plugin.json` and optional `logo.png` in the plugin folder.

Review `CONTRIBUTING.md` before opening a pull request.
